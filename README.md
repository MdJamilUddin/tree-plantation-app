# 🌳 বৃক্ষরোপণ তথ্য সংগ্রহ ওয়েব অ্যাপ
### Tree Plantation Data Collection Web App

> উপজেলা শিক্ষা অফিস, রাণীনগর, নওগাঁ — ১০০টি সরকারি প্রাথমিক বিদ্যালয়ের বৃক্ষরোপণ তথ্য সংগ্রহ, সংরক্ষণ ও রপ্তানির জন্য একটি ওয়েব অ্যাপ্লিকেশন।

---

## 📖 প্রকল্পের বিবরণ

এই অ্যাপ্লিকেশনের মাধ্যমে রাণীনগর উপজেলার ১০০টি সরকারি প্রাথমিক বিদ্যালয় থেকে নিম্নলিখিত তথ্য সংগ্রহ করা যায়:

- 🏫 **বিদ্যালয়ের তথ্য** — নাম, জেলা, উপজেলা, ইউনিয়ন, গ্রাম
- 🌱 **বৃক্ষরোপণের তথ্য** — ফলদ / বনজ / ঔষধি প্রজাতি ও সংখ্যা, তারিখ, জিও-কোঅর্ডিনেটসহ এলাকা
- 🎓 **শিক্ষার্থীর তথ্য** — নাম, পিতা-মাতার নাম, শ্রেণি, ঠিকানা, মোবাইল
- 👨‍🏫 **প্রধান শিক্ষকের তথ্য** — নাম ও মোবাইল নম্বর
- 📷 **ছবি আপলোড** — প্রতি বিদ্যালয় থেকে একটি ছবি
- 📝 **মন্তব্য** — ঐচ্ছিক

প্রতিটি বিদ্যালয়ের তথ্য সংরক্ষণের পর সারসংক্ষেপ টেবিল ও CSV রপ্তানি সুবিধা পাওয়া যায়।

## ✨ বৈশিষ্ট্য

| বৈশিষ্ট্য | বিবরণ |
|----------|--------|
| 📋 ১০০টি বিদ্যালয়ের ড্রপডাউন | `School List.doc` থেকে ডিকোড করা সম্পূর্ণ তালিকা |
| 📝 সম্পূর্ণ ফর্ম | `ছক.docx` অনুযায়ী সব ফিল্ড |
| 📷 ছবি আপলোড | প্রিভিউ + অটো রিসাইজ (৮০০px) |
| 📊 প্রগ্রেস বার | ০/১০০ পূর্ণতার দৃশ্যমান সূচক |
| 📈 সারসংক্ষেপ টেবিল | মোট চারা ও বিদ্যালয়ভিত্তিক তথ্য |
| ⬇️ CSV এক্সপোর্ট | বাংলা সাপোর্টসহ Excel-এ খোলার উপযোগী |
| 💾 অফলাইন সংরক্ষণ | `localStorage`-এ ডেটা সংরক্ষণ |
| 📱 রেসপন্সিভ ডিজাইন | মোবাইল ও ডেস্কটপে উপযোগী |
| 🔄 সম্পাদনা | আগের তথ্য লোড করে সংশোধন |
